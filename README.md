# وِرد | WIRD — بداية المشروع

هذا مشروع Flutter أولي لواجهة تطبيق وِرد.

## بناء APK من الهاتف عبر GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب Actions في المستودع.
3. اختر workflow باسم Build WIRD APK ثم Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل artifact باسم wird-android-apk.
5. فك ضغط artifact لتحصل على app-release.apk.

ملاحظة: هذه نسخة أولية للواجهة والتنقل فقط. الميزات الفعلية مثل مواقيت الصلاة والأذان والقرآن والإشعارات والمساجد تحتاج إلى تنفيذ وربط واختبار قبل الاستخدام العام.
